There is a particular kind of work that requires you to not think too hard about whether it will be received. You build the thing, and the building is the point.

The Irregular is that kind of project. A personal site rebuilt as a computational field. Every card is an object, every hover is an osnap, every command is a viewport operation. The web page as a CAD drawing.

A letter should cost something. The cost used to be stamps and ships. Now it is nothing, and so letters are nothing. This project is trying to restore the weight.

Development proceeds in two tracks. Fast, vibe-coded — it exists, it works. And hand-built alongside The Odin Project, every line reasoned through, no shortcuts. The work continues. This is the correct approach.
